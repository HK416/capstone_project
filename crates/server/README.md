# Capstone Project (Server)

## 컴파일 및 실행 방법

cmd 또는 터미널에서 아래의 명령어를 입력하세요.

<b>컴파일</b>
````shell
cargo build --bin server --release
````

<b>실행</b>
```shell
cargo run --bin server --release (-- mode(:port))
```
괄호 부분은 생략 가능합니다.  

|모드           |설명       |예시|
|:---:|:---|:---|
|localhost      |127.0.0.1 loopback주소로 서버를 엽니다. 외부에서 접속할 수 없습니다.|-- localhost:12345|
|public         |컴퓨터의 ip주소로 서버를 엽니다. 외부에서 접속할 수 있습니다.|-- public:12345|
|직접 입력|입력한 주소로 서버를 엽니다.|-- 127.0.0.1:12345|

포트 생략시 기본값은 7878입니다.  


### 스트레스 테스트(더미 클라이언트)
서버가 실행되어있는 상태에서 새로운 터미널을 열고 아래의 명령어를 입력하세요.
```shell
cargo run --example {더미클라이언트} --release
```

|더미클라이언트 목록|설명|완료|
|:---:|:---|:---:|
|client100|클라이언트 100개 접속, 각각 1초마다 랜덤 이동(주고 받는 패킷이 많아질때 병목 확인)|x|
|ar100|클라이언트 100개가 1초마다 접속/종료 반복(월드에 add/remove 횟수가 많아질때 병목 확인)|x|

<b>주의</b>
- `rust`의 패키지 관리자인 `cargo`가 필요합니다.
- `cargo`가 환경변수에 등록되어 있어야 합니다.
- 항상 `release`로 컴파일하고, 디버깅이 필요한 상황에서 `debug`모드를 사용하세요.
