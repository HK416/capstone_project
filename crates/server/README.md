# Capstone Project (Server)

## 컴파일 및 실행 방법

cmd 또는 터미널에서 아래의 명령어를 입력하세요.

<b>컴파일</b>
```shell
cargo build --bin server --release
```

<b>실행</b>
```shell
cargo run --bin client --release -- <OPTIONS>
```

### 옵션 목록
|명령어|기능|
|:---|:---|
| --num-threads <숫자> | (예정) 사용 가능한 최대 스레드의 갯수를 지정합니다. |
| --set-addr <주소> | 서버의 주소를 설정합니다. |

주소 부분에는 아래의 모드 중 하나를 입력할 수 있습니다.

|모드           |설명       |예시|
|:---:|:---|:---|
|localhost      |127.0.0.1 loopback주소로 서버를 엽니다. 외부에서 접속할 수 없습니다.|--set-addr localhost:12345|
|public         |컴퓨터의 ip주소로 서버를 엽니다. 외부에서 접속할 수 있습니다.|--set-addr public:12345|
|직접 입력|입력한 주소로 서버를 엽니다.|--set-addr 127.0.0.1:12345|

- 포트 생략시 기본값은 7878입니다.  
- 주소 옵션을 지정하지 않으면 localhost로 서버가 열립니다.  


### 스트레스 테스트(더미 클라이언트)
서버가 실행되어있는 상태에서 새로운 터미널을 열고 아래의 명령어를 입력하세요.
```shell
cargo run --example <더미 클라이언트 이름> --release -- <클라이언트 수> <주소>
```

|더미 클라이언트 목록|설명|
|:---:|:---|
|move|클라이언트 n개 접속, 각각 1초마다 랜덤방향 이동(주고 받는 패킷이 많아질때 병목 확인)|
|ad-rm|클라이언트 n개가 1~2초 사이의 랜덤한 대기시간을 가지고 접속/종료 반복(월드에 add/remove 횟수가 많아질때 병목 확인)|

- 클라이언트 수 생략시 기본값은 100개입니다.  
- 클라이언트 수 생략시 주소도 생략해야 합니다.  

<b>주의</b>
- `rust`의 패키지 관리자인 `cargo`가 필요합니다.
- `cargo`가 환경변수에 등록되어 있어야 합니다.
- 항상 `release`로 컴파일하고, 디버깅이 필요한 상황에서 `debug`모드를 사용하세요.
