# Client Examples
클라이언트 애플리케이션에 코드를 적용하기 전에 테스트 용도로 작성되는 예제 애플리케이션입니다.

## 컴파일 및 실행 방법

cmd 또는 터미널에서 아래의 명령어를 입력하세요.

````shell
cargo run --example <예제 이름> --release
````
